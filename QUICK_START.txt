STEP 5: Adjust Configuration (Optional)
----------------------------------------
Edit config.py to customize:
- Training time limit
- Quality preset
- Evaluation metrics
- Hyperparameters for each model type
- Imbalance handling strategy

KEY PARAMETERS TO ADJUST:

1. time_limit (seconds)
   - 600 = 10 min (quick test)
   - 1800 = 30 min (reasonable)
   - 3600 = 1 hour (good quality)
   - 7200+ = 2+ hours (best quality)

2. preset
   - 'medium_quality': Fast, decent results
   - 'good_quality': Balanced (recommended for testing)
   - 'high_quality': Better results, longer training
   - 'best_quality': Best results, longest training (recommended for production)

3. eval_metric (for highly imbalanced data)
   - 'roc_auc': Good overall measure
   - 'average_precision': Best for imbalanced (RECOMMENDED)
   - 'f1': Balance precision/recall
   - 'precision': Minimize false positives
   - 'recall': Minimize false negatives

4. resampling_method (in advanced pipeline)
   - 'none': No resampling (use sample weights only)
   - 'smote': Good for most cases
   - 'adasyn': Adaptive synthetic sampling
   - 'borderline_smote': Focus on borderline cases

Key metrics to check:
- ROC-AUC > 0.80: Good discrimination
- Average Precision > 0.50: Good for imbalanced data
- F1 Score: Balance between precision and recall
- Confusion Matrix: Check false positives and false negatives

- Focus on Average Precision and F1 score
- Check recall (ability to catch declines)
- Balance based on business cost of false positives vs false negatives

COMMON ISSUES & SOLUTIONS
==========================

Q: Training is too slow
A: Reduce time_limit, use 'medium_quality' preset, or sample your data for testing

Q: Poor performance on minority class (declines)
A: Try resampling_method='smote', optimize threshold for recall, or adjust class weights

Q: Out of memory
A: Reduce num_bag_folds to 3, sample your data, or use a machine with more RAM

Q: Model overfitting
A: Check validation scores in leaderboard, adjust hyperparameters, use more CV folds

Q: Need faster inference
A: Use predictor.persist() to keep models in memory, or use specific models from ensemble

TIPS FOR YOUR DATASET
======================

Given your 155:1 imbalance ratio:

1. RECOMMENDED SETTINGS:
   - eval_metric='average_precision' or 'f1'
   - resampling_method='smote' or 'adasyn' (try both)
   - use_sample_weights=True
   - Optimize threshold for your business needs

2. THRESHOLD SELECTION:
   - If false negatives are costly (missing declines): optimize for recall
   - If false positives are costly (declining good passes): optimize for precision
   - For balance: optimize for f1 or j_statistic

3. EVALUATION FOCUS:
   - Don't just look at accuracy (will be ~99% but meaningless)
   - Focus on: Average Precision, F1, Recall on minority class
   - Check confusion matrix: especially False Negatives (missed declines)

4. FEATURE ENGINEERING:
